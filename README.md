# AAC

## Setup instructions.

### Windows:

Add your groq API token to the slot in WindowsRun.bat.example, then rename the file to remove .example so the filename will be WindowsRun.bat
From there, you can run the .bat file to run the project.

### Linux, Mac:

Add your groq API token to the slot in MacLinuxRun.sh.example, then rename the file to remove the .example so the filename is MacLinuxRun.sh
From there, you can run the .sh file to run the project.

### General
Once the project is running, you can access it in the browser via localhost:5000

If venv is not installed, it can be installed directly through the command line, otherwise it's already installed with python/python3
